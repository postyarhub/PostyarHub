اتصال ساده وردپرس و ووکامرس به پست‌یار.

== راه‌اندازی ==
1. افزونه را از پیشخوان وردپرس نصب و فعال کنید.
2. در پست‌یار یک سایت وردپرسی بسازید و کد اتصال را بگیرید.
3. در وردپرس وارد «پست‌یار» شوید و کد اتصال را وارد کنید.
4. کانال‌ها و موارد ارسال خودکار را انتخاب و ذخیره کنید.
5. برای ارسال فوری، از بخش «ارسال دستی» چند محصول را انتخاب و ارسال کنید.

== نکته ==
برای استفاده روزمره نیازی به شورتکد، کد یا تنظیمات فنی نیست.
