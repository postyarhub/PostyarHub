# Postyar WordPress / Hamresan Feature Implementation v2

Current packaging target: Release v9 / WordPress plugin 1.7.0

## Scope
پیاده‌سازی مفهومی و اجرایی قابلیت‌های ارزشمند افزونه هم‌رسان روی معماری فعلی Postyar، بدون کپی‌کردن ساختار PHP افزونه مرجع.

## قابلیت‌های منتقل‌شده
- کتابخانه محتوای وردپرس: محصول، نوشته و برگه
- ویرایشگر انتشار با دو حالت «محتوای اصلی سایت» و «محتوای دلخواه من»
- ویرایش عنوان، متن و تصویر پیش از انتشار
- انتخاب روشن کانال با نمایش برجسته نام پلتفرم
- قالب پیام بدون نیاز به شورتکد یا کدنویسی: انتخاب ساده اجزای عنوان، متن، قیمت، موجودی، کد محصول و لینک
- ارسال گروهی محصولات
- ارسال دستی نوشته‌ها و محصولات از داشبورد
- ارسال‌های زمان‌بندی‌شده با انتخاب جدیدترین/تازه‌ویرایش‌شده/تصادفی/ویژه/تخفیف‌دار/موجود/ناموجود/پرفروش برای محصولات
- گزارش انتشار و خروجی CSV
- کتابخانه استیکر تلگرام با دریافت کامل مجموعه استیکر از Telegram API
- سهمیه تعداد سایت‌های WordPress در سطح Plan و اعمال آن در سرور
- رابط جدید WordPress Plugin با بخش‌های جداگانه اتصال، ارسال خودکار، همگام‌سازی و ارسال دستی

## موارد مرجع هم‌رسان
الگوهای Template، Campaign، Queue/Retry، Click/Report و Settings از افزونه `hwp-hamresan` نسخه 2.28.1 به‌عنوان مرجع رفتاری ممیزی شده‌اند. منطق Queue و Providerها عمداً روی معادل‌های موجود Postyar باقی مانده‌اند.

## نکته درباره Click Tracking
جدول `link_clicks` فعلی Postyar برای گزارش کلیک وجود دارد و WordPress report آن را مصرف می‌کند. پیاده‌سازی redirect/link-token کامل جداگانه هنوز در این بسته ادعای نهایی نشده است.
