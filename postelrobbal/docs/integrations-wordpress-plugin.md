# افزونه «پست‌یار» برای WordPress/WooCommerce

## هدف

این افزونه راه سادهٔ اتصال یک سایت WordPress یا فروشگاه WooCommerce به حساب Postyar است. کاربر نهایی نباید با API، شورتکد، متغیرهای فنی یا تنظیمات برنامه‌نویسی درگیر شود.

## مسیر استفادهٔ کاربر

1. در Dashboard پست‌یار، در بخش «ووکامرس»، یک سایت WordPress اضافه می‌شود.
2. پست‌یار یک «کد اتصال» تولید می‌کند و فقط همان کد باید در WordPress وارد شود.
3. در WordPress افزونه نصب و فعال می‌شود.
4. در منوی «پست‌یار» کد اتصال وارد و دکمهٔ «اتصال» زده می‌شود.
5. پس از اتصال، کانال‌های فعال و تنظیمات ارسال از Postyar خوانده می‌شوند.
6. کاربر فقط انتخاب می‌کند چه چیزهایی خودکار ارسال شوند.

## قابلیت‌های فعلی افزونه

- اتصال با یک کد سادهٔ اتصال.
- ارسال خودکار محصول جدید.
- ارسال خودکار هنگام تغییر قیمت محصول.
- ارسال خودکار هنگام تغییر موجودی.
- ارسال خودکار هنگام ویرایش اطلاعات محصول.
- ارسال خودکار نوشته یا برگهٔ جدید.
- ارسال خودکار هنگام ویرایش نوشته یا برگه.
- انتخاب تا ۵ کانال فعال از کانال‌های Postyar.
- سه سبک پیام از پیش آماده: «فروشگاهی و کامل»، «ساده و کوتاه»، «فروش ویژه».
- امکان ارسال تصویر محصول.
- همگام‌سازی دستی تا ۵۰ محصول منتشرشده.
- ارسال دستی و گروهی تا ۲۰ محصول انتخاب‌شده، مستقل از روشن/خاموش بودن ارسال خودکار.
- پشتیبانی از محصولات WooCommerce و تغییرات Variation برای انتشار روی محصول اصلی.
- شناسایی واحد پول تومان و ریال در WooCommerce؛ در واحدهای ناشناخته قیمت عددی به Postyar اعلام نمی‌شود تا قیمت اشتباه ارسال نشود.
- استفاده از WP-Cron با زمان کوتاه و جلوگیری از زمان‌بندی تکراری یک رویداد.
- ارسال اعتبارنامه فقط از طریق هدرهای HTTPS به API.
- هیچ شورتکدی برای استفادهٔ روزمره نیاز نیست.

## رفتار انتخاب کانال

اگر کاربر هیچ کانالی را انتخاب نکند، پست‌یار از همهٔ کانال‌های فعال آن حساب استفاده می‌کند. این رفتار عمداً طوری طراحی شده که کاربر با «صفر کانال انتخاب‌شده» به وضعیت ظاهراً خراب نرسد.

## امنیت اتصال

Postyar در سمت سرور مقدار اصلی Secret را به صورت hash نگه می‌دارد. افزونه مقدار لازم برای اتصال را در تنظیمات خصوصی WordPress ذخیره می‌کند و در رابط عمومی سایت نمایش نمی‌دهد. اتصال عمومی فقط با `X-Postyar-Site-Key` و `X-Postyar-Secret` انجام می‌شود.

## APIهای مورد استفاده

- `GET /api/v1/webhooks/wordpress/settings`
- `PUT /api/v1/webhooks/wordpress/settings`
- `POST /api/v1/webhooks/wordpress`

مسیرهای عمومی بالا با Site Key و Secret اختصاصی همان سایت احراز هویت می‌شوند.


## شرایط استفاده از اتصال

اتصال WordPress/WooCommerce در منطق اشتراک پروژه یک قابلیت پلنی است. پلن‌های رایگان و پایه طبق تنظیمات فعلی قابلیت `woocommerce` ندارند؛ پلن‌های حرفه‌ای، تجاری و سازمانی این قابلیت را دارند. اگر حساب روی پلن فاقد این قابلیت باشد، داشبورد نباید کاربر را با پیام فنی «اجازه ندارید» سردرگم کند و باید او را به ارتقای پلن راهنمایی کند. Migration شماره `0017_repair_woocommerce_feature_flags.sql` فقط فلگ موردنظر پلن‌های حرفه‌ای، تجاری و سازمانی را روی دیتابیس‌های قدیمی ترمیم می‌کند و داده‌ای را حذف نمی‌کند.

## مرز قابلیت‌ها

این افزونه جایگزین کامل Dashboard پست‌یار نیست. Template Library مشترک، Campaign Engine، گزارش‌های کلیک/UTM و کتابخانهٔ Emoji/Sticker در هستهٔ Postyar باید به‌صورت مستقل و tenant-scoped توسعه یابند و نباید با Options یا WP-Cron افزونه قاطی شوند.
