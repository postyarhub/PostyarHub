# Postyar Release v9 — WordPress / Hamresan feature integration

این Release نسخهٔ یکپارچهٔ قابلیت‌های WordPress/WooCommerce و قابلیت‌های منتخب ممیزی‌شده از افزونهٔ هم‌رسان است.

## قابلیت‌های کاربر نهایی
- اتصال سادهٔ سایت وردپرس با کد اتصال.
- نمایش محصولات، نوشته‌ها و برگه‌های همگام‌شده.
- ویرایش عنوان، متن و تصویر پیش از انتشار.
- انتخاب «محتوای اصلی سایت» یا «محتوای دلخواه من».
- انتخاب کانال‌ها با نمایش واضح و پررنگ نام پلتفرم: تلگرام، بله، روبیکا.
- قالب پیام بدون نیاز به شورتکد و کدنویسی.
- ارسال گروهی محصولات.
- ارسال‌های زمان‌بندی‌شده با انتخاب جدیدترین، تازه‌ویرایش‌شده، تصادفی، ویژه، تخفیف‌دار، موجود، ناموجود و پرفروش.
- گزارش ارسال و خروجی CSV.
- کتابخانهٔ استیکر تلگرام با دریافت کامل هر مجموعهٔ انتخاب‌شده از Telegram API.
- سهمیهٔ تعداد سایت WordPress در سطح پلن و کنترل آن در سمت سرور.

## افزونهٔ WordPress
نسخهٔ افزونه: 1.7.0

مراحل استفاده برای کاربر عادی:
1. افزونه نصب و فعال شود.
2. کد اتصال از داشبورد پست‌یار گرفته شود.
3. کد در صفحهٔ پست‌یار داخل پیشخوان وردپرس وارد شود.
4. کانال‌ها و رفتار ارسال خودکار انتخاب شود.
5. در صورت نیاز، محصولات و نوشته‌ها همگام شوند.

هیچ شورتکد یا تنظیمات برنامه‌نویسی برای استفادهٔ روزمره لازم نیست.
