# پُست‌یار (PostyarHub)

این مخزن شامل دو snapshot فیلترشده از پوشه‌های اصلی هاست است:

- `postelrobbal/`: کد منبع پروژه، تنظیمات نمونه و migrations؛ بدون فایل‌های محیطی، رازها، وابستگی‌ها و خروجی‌های ساخت.
- `public_html/`: نسخهٔ عمومی وب‌سایت، شامل `index.html`، `.htaccess` و assetهای وب که روی ریشهٔ عمومی هاست قرار دارند.

این مخزن برای نگهداری سورس و هم‌ترازکردن نسخهٔ عمومی وب‌سایت است؛ فایل‌های زندهٔ هاست با این اسکریپت تغییر نمی‌کنند. فایل‌های `.env`، اعتبارنامه‌ها، کلیدهای خصوصی، وابستگی‌ها، کش‌ها، لاگ‌ها، بکاپ‌ها، dumpهای دیتابیس و آرشیوها در snapshot قرار نمی‌گیرند.
